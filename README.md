# Human Activity Recognition

A machine-learning project focused on classifying human activities from sensor data.

## Project Summary

The project explores human activity classification using inertial sensor data and compares classical machine-learning and deep-learning approaches.

The reported project result is **96% classification accuracy** for the evaluated configuration.

## Focus Areas

- Human activity classification from sensor data
- Feature-based machine learning
- Model comparison and evaluation
- Computer vision / ML experimentation related to activity recognition

## Models Explored

The project work includes experiments with models such as:

- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)
- Random Forest
- Gradient Boosting
- Neural-network-based approaches

## Reported Result

**96% accuracy** on the evaluated human-activity-classification setup.

The exact result depends on the dataset split, preprocessing, feature representation, and model configuration used during evaluation.

## Repository Status
